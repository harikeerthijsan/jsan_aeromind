# UI reference: Sneat Bootstrap Admin

- Reference: https://demos.themeselection.com/sneat-bootstrap-html-admin-template-free/html/
- Reviewed: 2026-11-04
- Purpose: visual/layout reference for the AeroMind tower-inspection interface.

## Patterns adopted

- Detached, rounded top navigation with a light elevation shadow.
- Soft neutral application background separating navigation, cards, and work surfaces.
- Border-light cards with consistent 12–14 px radii and restrained shadows.
- Compact card headers, toolbars, badges, and KPI hierarchy.
- Responsive content gutters that narrow cleanly on tablets and phones.
- Clear selected navigation pills while retaining AeroMind's dark sidebar and blue brand palette.

## Patterns not adopted

- Bootstrap runtime and Sneat JavaScript dependencies; this project remains React and project-native CSS.
- E-commerce, finance, and generic analytics widgets that do not fit telecom inspection workflows.
- Sneat logos, illustrations, icons, fonts, or packaged assets.
- Exact visual duplication. The reference influences spacing and hierarchy only.

## Usage note

Treat this URL as a design reference when refining new pages. Reuse the project's existing components and tokens first. Verify the upstream package license before ever copying source or assets; the current implementation does not copy them.
